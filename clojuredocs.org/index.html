    Interactive ClojureDocs¶

    About Interactive ClojureDocs

    ClojureDocs Interactive is an experimental project seeking feedback from the Clojure community.

    The documentation, usage signatures, examples, notes, related links, and contributor information come from the public ClojureDocs JSON export. This site keeps a tracked snapshot of 500 selected pages and generates the index and individual pages from that data. The page selection, interactive interface, and decisions about which examples can run are maintained by this project.

    Runnable examples execute locally in your browser using Glojure compiled to WebAssembly. Focusing an editor or selecting its run button creates a fresh WebAssembly instance for that evaluation. All top-level forms run in order in that instance, so later forms can use definitions from earlier ones. The output shows each form's result, including nil, together with anything the code prints. Collection results are limited to 100 items and 20 nesting levels, with an ellipsis when truncated. Evaluation stops at the first error. Once active, the editor evaluates changes automatically after a short pause. Examples that are not known to run in this browser-based Glojure environment are marked "May have evaluation errors." They remain editable and runnable, but may depend on REPL state from another session, JVM APIs, external libraries, or other context that is unavailable here.

    The original prose and examples remain attributed to their ClojureDocs contributors, with a link back to the matching source page's example.
