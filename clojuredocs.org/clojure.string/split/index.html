    clojure.string/split¶

    View this page on ClojureDocs

    Type: function Added: Clojure 1.2 Examples: 8 Runnable: 4 
    ([s re] [s re limit])

    Splits string on a regular expression. Optional argument limit is the maximum number of parts. Not lazy. Returns vector of the parts. Trailing empty strings are not returned - pass limit of -1 to return all.

    Note by Domon¶
    

    Hi, cocoOS. You may want to do it like this:
    

    user=> (use '[clojure.string :only (split)])
nil
user=> (def bignumber "2938434")
#'user/bignumber
user=> (split bignumber #"")
["" "2" "9" "3" "8" "4" "3" "4"]

    


    You will have to filter out the empty string.
    


    

    But there are other ways, like:
    

    user=> (map str (vec bignumber))
("2" "9" "3" "8" "4" "3" "4")

    


    Note by Iceland_jack¶
    

    user=> (seq "2938434")
(\2 \9 \3 \8 \4 \3 \4)

    


    might also be what you want.

    Note by olivergeorge¶
    

    When limit=1 the original string is returned
    

    (clojure.string/split "abcd" #"a" 1)
=> ["abcd"]

(clojure.string/split "abcd" #"a" 2)
=> ["" "bcd"]

    Note by rux¶
    

    There is a change in behaviour between Java 7 and Java 8 that can affect the returned values.  "When there is a positive-width match at the beginning of this string then an empty leading substring is included at the beginning of the resulting array. A zero-width match at the beginning however never produces such empty leading substring." was added to the docs for split().
    

    Both run with Clojure 1.8, the code below splits a string based on capital letters, but...
    

    in Java 7
    

    (clojure.string/split "PrimaryEmailAddr" #"(?=[A-Z])")
=> ["" "Primary" "Email" "Addr"]
    


    ⁠⁠⁠in Java 8
    

    (clojure.string/split "PrimaryEmailAddr" #"(?=[A-Z])")
=> ["Primary" "Email" "Addr"]
